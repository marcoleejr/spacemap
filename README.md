# SpaceMap

**Español:** [README.es.md](README.es.md)

SpaceMap is a fast, local-first macOS disk-usage inspector. It scans a folder (your home folder by default) and turns it into an interactive treemap, so you can see where space lives, inspect any item in context, and move things to Trash — always with confirmation, never permanently deleted by the app.


## Features

- Interactive nested treemap: **Size**, **Files**, and **Age** modes
- Hidden files and apparent-size toggles, adjustable depth (1–8)
- Breadcrumb navigation, keyboard-first control, name filter
- Selection inspector with share-of-scan, file counts, age, and kind
- **Worth a look**: regenerable candidates first (build outputs, caches, agent workspaces, large repositories), stale leftovers after
- Disk panel with free/used/total for the scanned volume
- Reveal in Finder and Move to Trash (confirmed)
- Incremental, cancellable scans that never follow symlinks or cross volumes
- Works with partial results when Full Disk Access is unavailable
- Localized in 6 languages (English, Spanish, Portuguese, French, German, Japanese) — follows the system language, light and dark appearance included

## Requirements

- macOS 14+
- Swift 6 toolchain (only for building from source)

## Build

```sh
scripts/build-app.sh   # produces build/SpaceMap.app
open build/SpaceMap.app
```

The bundle embeds the compiled `Localizable` catalog (built by the Swift
toolchain from `Sources/SpaceMap/Resources/Localizable.xcstrings`, no Xcode
needed) and an app icon generated by `scripts/make-icon.sh` from
`scripts/icon.swift`.

## Tests

```sh
swift test        # 22 XCTest cases: classifier, squarify, scanner, catalog
swift run -c release spacemap-bench ~   # raw engine throughput on ~
```

## Privacy

SpaceMap does no networking. All scanning is local. Without Full Disk Access,
TCC-protected folders (`~/Library/Mail`, `~/Library/Messages`,
`~/Library/Safari`, `~/Library/Photos`, `~/Library/Calendars`, Photos
libraries) are skipped by path — the app never triggers privacy prompt
cascades — and the banner offers a shortcut to enable access.

### Signing and Full Disk Access

macOS remembers Full Disk Access per code signature. An ad-hoc signature
changes on every build, so macOS would forget the grant after each rebuild.
`scripts/build-app.sh` therefore signs with the first `Apple Development`
identity in your keychain (override with `SPACEMAP_SIGN_IDENTITY`) and only
falls back to ad-hoc with a warning. SpaceMap detects access by actually
opening a protected item (`TCC.db`, `~/Library/Safari`, …) and re-checks
whenever it becomes active, so the banner clears without a restart after you
grant access in System Settings.

## Shortcuts

| Key | Action |
|---|---|
| `space` | mark for review |
| `enter` | open (zoom into a folder / reveal a file) |
| `⌫` | up one folder |
| `c` | review marked items |
| `hjkl` / arrows | move selection |
| `/` | filter by name |
| `[` `]` | depth |
| `t` | cycle Size / Files / Age |
| `0` | reset to scan root |
| `r` | rescan |
| `?` | all shortcuts |

## Layout

- `Sources/SpaceMap` — SwiftUI app (views, theme, localizations access)
- `Sources/SpaceMap/Resources/Localizable.xcstrings` — translation source of truth
- `Sources/SpaceMapCore` — scan engine, classifier, treemap layout, formatting
- `Sources/SpaceMapBench` — `spacemap-bench` CLI throughput probe
- `Tests/SpaceMapCoreTests` — test suite (incl. catalog coverage)
- `scripts/` — `build-app.sh`, `make-icon.sh`, `icon.swift`, `strings.py`
- `docs/screens/` — real captures from a home-folder scan
